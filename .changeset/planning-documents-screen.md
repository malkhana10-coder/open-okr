A new Planning entry in the sidebar opens a sector's source documents. A member with edit on the sector uploads a PDF strategy, sees whether it has been read and how many pages it has, and opens each page as the product read it. A document or a page that was read poorly is marked, so a quotation from it can be checked against the original.
