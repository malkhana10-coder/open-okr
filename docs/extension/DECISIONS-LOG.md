# سجل القرارات المتخذة بالتفويض

قرارات اتخذها المنفِّذ دون انتظار صاحب المنتج، ليراجعها دفعة واحدة عند معلَم «العرض القابل للنقر».

**التفويض** (2026-11-21): كامل حتى المعلَم، للجلسات 9 إلى 16. حين يُحتاج قرار تؤخذ التوصية ويُكمَل العمل، ويُسجَّل القرار هنا.

**ما لا يشمله التفويض، ويُنتظر فيه صاحب المنتج:**

1. حذف بيانات أو ترحيل لا يُتراجع عنه.
2. تبعية جديدة برخصة غير MIT أو Apache أو BSD أو OFL.
3. تعديل على النواة يتجاوز 30 سطراً، أو يغيّر سلوكاً أمنياً أو صلاحيات.
4. أي شيء يخالف تصميماً اعتُمد صراحة.

**مراجع مستقل:** في نهاية كل جلسة وقبل الدفع، وكيل فرعي لم يرَ العمل يراجع فرق الجلسة: أخطاء منطقية، ثغرات صلاحيات، اختبارات لا تختبر شيئاً فعلياً، ومخالفات `CLAUDE.md`. الملاحظات الجدية تُصلح قبل الدفع، ونتيجة المراجعة تُذكر في تحديث الجلسة.

**كلفة التراجع:** منخفضة = تعديل في ملف أو اثنين دون ترحيل. متوسطة = ترحيل جديد أو تعديل عدة ملفات. مرتفعة = إعادة بناء جزء أو ترحيل بيانات.
